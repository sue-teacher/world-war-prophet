# 전쟁 예언자 · 제1차 세계대전 학습 웹앱

중학교 2학년 세계사 학습용 인터랙티브 웹앱입니다. 학생은 '전쟁 예언자'가 되어
지도·인물·신문·통계 등 여러 증거를 종합하고, 다음에 벌어질 사건을 예언하며
제1차 세계대전의 흐름을 발견합니다.

## 미션 구성

1. **갈라진 유럽의 지도** — 삼국동맹과 삼국협상 찾기
2. **발칸의 화약고** — 사라예보 사건 예언하기
3. **끝나지 않는 전쟁** — 참호전·총력전 발견하기
4. **바뀐 전세, 다가오는 종전** — 미국 참전과 동맹국의 항복 예언하기
5. **평화 조약인가, 새로운 갈등의 씨앗인가** — 베르사유 체제 평가하기
6. **종합 활동** — 사건 배열·인과 사슬·최종 예언 보고서

## 기술

- 순수 HTML / CSS / JavaScript (빌드 도구·프레임워크 없음)
- 정적 사이트로 어떤 호스팅에도 그대로 배포 가능

## 로컬에서 실행

빌드가 필요 없습니다. `index.html`을 브라우저로 열거나, 간단한 정적 서버를 사용하세요.

```bash
# 예: Python 내장 서버
python -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 파일 구조

| 파일 | 역할 |
| --- | --- |
| `index.html` | 앱의 뼈대 (상단 진행바, 무대, 토스트) |
| `styles.css` | 양피지 테마 스타일 |
| `data.js` | 프롤로그·5개 미션·종합 활동의 학습 콘텐츠 |
| `app.js` | 화면 라우팅, 미션 로직, 힌트·점수 시스템 |

## 배포

정적 파일이므로 Vercel에서 별도 빌드 설정 없이 배포됩니다. `vercel.json`은
`cleanUrls` 정도만 지정합니다.
